# A1 — Event bus: findings and decisions (2026-11)

Companion to section A1 of [`2026-11_loose_ends.md`](2026-11_loose_ends.md) (TASK-087). That
register is left as it is; this file holds the detail.

All counts come from the static scan in
[`tests/quality/test_no_orphan_ui_events.py`](../../tests/quality/test_no_orphan_ui_events.py),
which now sees every publish wrapper (`publish`, `publish_event`, `emit_event`, `_publish_event`,
`_publish_model_event`, `_publish_arduino_ui`), every subscribe form (`subscribe`,
`register_handler`, `register_direct_handler`, `bind_callback`, loops over a collection such as
`_EVENTS_TO_HANDLE`), `Event(UIEvents.X)` in positional or keyword form, and events chosen into a
local variable before publishing (`reports_tree_manager.py`, `progress_tracking_coordinator.py`,
`main_view_model_runtime.py`).

directions. A probe test drives the scanner over a synthetic module containing every form above.

## Item 6 — never referenced outside `event_bus_v2.py` (38)

Decision for all 38: **delete** the member, together with its `_PAYLOAD_TYPES` entry and the
payload class when nothing else uses it. None has a publisher or a subscriber, and none was
found to be part of a persisted contract. The tokens persisted in project files are not
`UIEvents` names.

`ANALYSIS_COMPLETED`, `ANALYSIS_STARTED`, `APP_CLOSE`, `ARDUINO_LOG_EVENT`, `ARDUINO_SETUP`,
`CALIBRATION_RUN_LIVE`, `DETECTOR_SETUP`, `DETECTOR_SETUP_ZONES`, `DETECTOR_UPDATE_ZONES`,

## Item 7 — worker-thread publishers whose subscribers write Tk without marshalling

confirmed paths are listed. Every hop was read in the code. Neither path was reproduced at

(`progress_tracking_coordinator.py:371-374`), and `EventDispatcher` already has
