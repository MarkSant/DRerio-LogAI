# Strings that look Portuguese but MUST NOT be translated.
#
# Read by scripts/i18n_scan.py and by
# tests/i18n/test_no_untranslated_literals.py. One pattern per line; blank lines
# and lines starting with '#' are ignored. A literal matches when it CONTAINS
# the pattern (case-sensitive), so "Grupo_" covers "Grupo_{group}" and
# "Grupo_Sem_Grupo" alike.
#
# A pattern written "=grupo" matches only when the literal is EXACTLY that.
# Use it for any protected token that is also an ordinary Portuguese word:
# as a substring, "grupo" exempted every sentence containing the word and hid
# seven real interface strings from the scanner while it reported TOTAL: 0.
# Prefer "=" whenever the protected value is a complete literal (a dict key, a
# sentinel, a column name) rather than a prefix that gets formatted into.
#
# Everything here is a persistence contract: a value written to disk, used to
# build a path, or used as a dictionary key that reaches Parquet/JSON/XLSX.
# Translating one of these does not produce an English app -- it produces an app
# that cannot read the projects it wrote yesterday. Where such a token is
# *displayed*, translate at the display boundary only (render _("Unassigned")
# for a stored "Sem_Grupo"); never change what is stored.
